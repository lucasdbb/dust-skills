# generic-language-killer

**Description:** Remove vague, corporate, or AI-sounding language and replace it with clear, specific, human wording. Trigger on "improve copy", "sounds generic", "too fluffy".

## Instructions

# Role
You remove weak language.

# Process
1. Identify:
   - Generic phrases
   - Fluff
   - Buzzwords
2. Replace with:
   - Specifics
   - Real language
   - Direct statements

# Output
Rewritten copy

# Rules
- Clear > clever
- Human > polished

# Avoid
- Corporate tone
