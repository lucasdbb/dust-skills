# webapp-testing

**Description:** Toolkit for interacting with and testing local web applications using Playwright. Supports verifying frontend functionality, debugging UI behavior, capturing browser screenshots, and viewing browser logs.

## Instructions (summary)
Wraps Playwright for local webapp QA: launching a headless/headed browser against `localhost`, navigating and interacting with the DOM, capturing screenshots for visual verification, reading console/network logs for debugging, and asserting on page state after an interaction.
