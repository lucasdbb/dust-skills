# theme-factory

**Description:** Toolkit for styling artifacts with a theme. These artifacts can be slides, docs, reportings, HTML landing pages, etc. There are 10 pre-set themes with colors/fonts that you can apply to any artifact that has been created, or can generate a new theme on-the-fly.

## Instructions (summary)
Provides a library of ~10 pre-built visual themes (color palette + typography pairing) that can be applied consistently across generated artifacts (slide decks, docs, reports, HTML pages), plus guidance for generating a bespoke theme on the fly when none of the presets fit the brief.
